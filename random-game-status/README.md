# Random Game Status

Sets a random game from your own list as your "Playing" status. Each game lasts a random time (default 21-53 minutes), then it switches to a new one.

## Features

- **Random games:** Picks from an editable list and never repeats the same game twice in a row.
- **Random duration:** Each session lasts a random time between your min and max (default 21-53 min).
- **Resumes where it left off:** The current game and remaining time are saved. Reopen Discord and it continues the same game.
- **Closed-app mode:** By default the timer pauses while Discord is closed. Turn on "Keep counting while Discord is closed" to make it run in real time.
- **Live timer:** Discord shows the elapsed time for the current game.
- **Controls:** Skip to a new game, add/remove games, reset the list, enable/disable.

## Installation

Add the plugin URL to Revenge/Vendetta (after hosting this folder):
```
https://ilickft.github.io/revenge-plugins/random-game-status/
```

## Visibility

The status is sent through Discord's own presence update, so friends and servers see it like a normal game. Make sure Settings > Activity Privacy > "Share my activity" is on and your status is not Invisible.

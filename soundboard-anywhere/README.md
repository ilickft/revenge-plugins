# Soundboard Anywhere

Use soundboard sounds from any server without Nitro on Discord Mobile.

## Features

- **Unlock Cross-Server Sounds:** Removes Nitro gating on soundboard sounds across servers.
- **Unlock Picker UI:** Disables client-side locks, unavailable reasons, and disabled states so all sounds remain interactive in the picker.
- **Client-Side Guard Removal:** Patches `sendSoundboardSound` and `useSendSoundboardSound` to bypass local Nitro checks.

## Installation

Add the plugin URL to Revenge/Vendetta:
```
https://ilickft.github.io/revenge-plugins/soundboard-anywhere/
```

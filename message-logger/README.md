# Message Logger

Keeps deleted and edited messages visible in chat with native-style decreased opacity.

## Features

- **Ghost Deleted Messages:** When a message is deleted (by another user or yourself), it stays visible in chat instead of disappearing.
- **Decreased Opacity Styling:** Deleted messages are rendered with muted brightness/opacity (`-# ` subtext markdown & native chat dimming), without adding trash bins or brackets.
- **Preserved Attachments:** Deleted attachments (photos, videos, audio, files) stay visible and viewable without disappearing or causing app crashes.
- **Edit History:** When a message is edited, the original message is displayed with dimmed opacity labeled `*Original Message*`, followed by the new edited message at normal brightness labeled `*Edited Message*`.
- **Self-Delete Protection:** Preserves messages you delete yourself so they remain in your chat history dimmed.

## Installation

Add the plugin URL to Revenge/Vendetta:

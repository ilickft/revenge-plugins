# Emoji Anywhere

Send custom, animated, and cross-server emojis anywhere on Discord without Nitro.

## Features

- **No Nitro Required:** Sends custom and animated emojis from any server by converting them into clean Markdown image links (`[label](cdn_url)`).
- **Smart Server Emoji Detection:** Server emojis that are already available in your current channel without Nitro stay as normal standard emojis, never embedded as links.
- **Customizable Label:** Configure what label appears inside the link brackets (e.g. `:)`, `{{name}}`, invisible filler character, etc.).
- **Picker Unlocked:** Removes the server lock and grayed-out state from external emojis in the emoji picker so you can select them freely.
- **Code Block Protection:** Never touches emojis inside code blocks or inline backticks.

## Settings

Open the plugin settings in Revenge/Vendetta to pick presets (such as `:)`, `{{name}}`, or invisible spaces) or type your own custom label format.

## Installation

Add the plugin URL to Revenge/Vendetta:
```
https://ilickft.github.io/revenge-plugins/emoji-anywhere/
```

# Discordo Startup Sound

A Revenge/Vendetta plugin that plays Discord's iconic Japanese "DISCORDO!" startup sound chime whenever Discord launches.

## Features

- **Automatic Startup Chime:** Plays the official Discord audio easter egg whenever the app starts up.
- **Settings & Test Button:** Includes a built-in settings page with a button to preview/test the sound at any time.
- **Multi-Engine Audio Fallback:** Leverages native `DCDSoundManager`, Discord's internal `SoundUtils`, or the standard Audio API.

## Installation

Add the plugin URL to Revenge/Vendetta:
```
https://ilickft.github.io/revenge-plugins/discordo/
```

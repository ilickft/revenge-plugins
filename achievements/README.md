# Achievements

Unlock 270+ obtainable achievements with top toast banners, sounds, profile Orb shortcut, bio progress sync, and streak tracking.

## Features

- **270+ Discord-Ready Achievements:** Cleaned of unobtainable Telegram artifacts (forwards, video notes, stories, contacts, locations, invoices, to-dos) with all remaining achievements fully obtainable on Discord.
- **Profile Shortcut (Like the Orb):** Sleek pill shortcut button on your user profile showing your progress (`[🏆 X/273 (Y%)]`), tapping which opens the full Achievements modal with category filtering and criteria.
- **Bio Progress Sync:** Automatically update your Discord About Me bio with your achievements progress, featuring an intelligent 3-second debounce delay to prevent Discord rate limits and spam when unlocking multiple achievements. (Disabled by default in Settings).
- **Exact Audio Chimes:** Uses the exact `default.ogg` (Common & Uncommon) and `rare.ogg` (Rare, Epic, Legendary, Mythic, Secret) sound files.
- **Top Toast Notifications:** Displays floating top toasts via Vendetta toast API when an achievement is unlocked.
- **Enhanced Tracking:** GIF detection accurately counts Discord GIF picker (Tenor/Giphy links, .gif/.gifv URLs, files, embeds), spoilers, custom server emojis, and multi-streaks without duplicate counting.
- **Notification Controls:** Toggle sounds and toasts on or off, with instant sound test buttons in settings.
- **Bilingual Support:** Full English and Russian localization.

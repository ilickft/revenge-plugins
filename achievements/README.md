# Achievements

Tracks Discord activity and unlocks milestone achievements with audio chimes, toasts, and a profile shortcut.

## Features

- **270+ Discord Achievements:** Milestones for messages, media, streaks, reactions, and interactions.
- **Profile Shortcut:** Shows current achievement progress on your user profile. Tapping opens the achievements viewer.
- **Bio Progress Sync:** Optionally display achievements progress in your Discord About Me bio (disabled by default in settings).
- **Audio Chimes & Toasts:** Plays audio chimes and shows top toast banners upon unlocking achievements.
- **Settings Controls:** Toggle sounds and toasts on or off, test sounds, or view unlocked achievements.

## Installation

Add the plugin URL to Revenge/Vendetta:
```
https://ilickft.github.io/revenge-plugins/achievements/
```

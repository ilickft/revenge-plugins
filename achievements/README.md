# Achievements

Unlock 308+ achievements with top toast banners, sounds, and streak tracking ported from AyuGram.

## Features

- **308 Authentic Achievements:** Full port of all AyuGram achievements across 13 categories (Messages, Media, Social, Time, Streaks, Special, Secret, Reactions, Collector, Explorer, Interactive, Luck, Veteran).
- **Exact Audio Chimes:** Uses the exact `default.ogg` (Common & Uncommon) and `rare.ogg` (Rare, Epic, Legendary, Mythic, Secret) sound files.
- **Top Toast Notifications:** Displays floating top toasts via Vendetta toast API when an achievement is unlocked.
- **Live Progress & Stats:** Built-in settings screen tracking your unlocked achievements (X / 308), percentage progress bar, category filters, and detailed criteria.
- **Notification Controls:** Toggle sounds and toasts on or off, with instant sound test buttons in settings.
- **Bilingual Support:** Full English and Russian localization.

## Installation

Add the plugin URL to Revenge/Vendetta:
```
https://ilickft.github.io/revenge-plugins/achievements/
```

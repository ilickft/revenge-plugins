# No Embeds

Automatically suppress link embeds from messages you send and edit.

## Features

- **Embed Suppression:** Wraps outgoing URLs in `<...>` angle brackets, which Discord interprets as suppressing the embed preview.
- **Code Block Protection:** Safely ignores URLs inside code blocks (`` ` `` or ```` ``` ````).
- **Edit Support:** Also applies when editing existing messages.

## Installation

Add the plugin URL to Revenge/Vendetta:
```
https://ilickft.github.io/revenge-plugins/no-embeds/
```

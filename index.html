How to Install Any Plugin

Follow these quick steps to install any plugin directly into your Revenge client:

1
Click Copy Link on any plugin card above to copy its exact install URL.
2
In Discord, go to Settings → Plugins (under the Revenge section).
3
Tap the + button in the top-right corner of the plugins screen.
4
Paste the copied URL into the box and tap Install to activate!

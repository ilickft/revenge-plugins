# App Icons

Unlocks all Discord premium app icons without Nitro. Freely choose any official icon from Discord's appearance settings without a subscription.

## Features

- **Unlock All Premium Icons:** Removes Nitro locks from all official alternate app icons on Discord mobile.
- **Native Discord Integration:** Works seamlessly inside Discord's native App Icon selector under **Settings → Appearance → App Icon**.
- **Upsell Bypass:** Strips Freemium restrictions and suppresses Nitro upgrade sheets when selecting icons.
- **Client-Side Application:** Applies your chosen icon cleanly and reliably.

## Installation

Add the plugin URL to Revenge/Vendetta:
```
https://ilickft.github.io/revenge-plugins/app-icons/
```

# Pet-Pet

Add a `/petpet` slash command to pet anyone in the server with an animated petpet petting GIF.

## Features

- **Slash Command:** Type `/petpet` in any chat to generate and send an animated pet-pet GIF.
- **User Option:** Accepts an optional `user` argument to target any specific user.
- **Reply Auto-Detection:** If used without a `user` argument while replying to a message, automatically pets the author of that message. Defaults to yourself if neither is specified.
- **Animated Avatars:** Full support for both static and animated (GIF) user avatars.

## Usage

- `/petpet` (while replying to someone): Pets the user you're replying to.
- `/petpet user:@username`: Pets the specified user.
- `/petpet`: Pets your own avatar.

## Installation

Add the plugin URL to Revenge/Vendetta:

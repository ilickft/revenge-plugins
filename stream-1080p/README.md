# Stream 1080p

Unlocks 1080p resolution, 60 FPS, and Source stream quality for screen sharing on Discord without Nitro.

## Features

- **1080p / 60 FPS / Source:** Unlocks full 1080p resolution, 60 frames per second, and source stream settings.
- **Client-Side Nitro Bypass:** Removes Nitro requirement locks from the stream resolution and frame rate selectors.
- **No Boost Requirements:** Strips server booster tier requirements from stream preset settings.

## Installation

Add the plugin URL to Revenge/Vendetta:
```
https://ilickft.github.io/revenge-plugins/stream-1080p/
```

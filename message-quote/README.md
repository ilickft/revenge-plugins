# Message Quote

Turn any Discord message or text into an authentic Discord-style PNG quote card and send it directly to the chat.

## Features

- **Slash Command (`/quote`):** Reply to any message and type `/quote` to capture it as a high-resolution PNG card and post it to the channel.
- **Authentic Discord Styling:** Renders the author's avatar, display name, role color, local timestamp (e.g. *Today at 12:23 PM*), and formatted message content on a sleek dark Discord background.
- **Custom Quotes:** Quote custom text using `/quote text:...`, or attribute quotes to anyone using `/quote user:@someone`.
- **Role Color Support:** Automatically uses the member's server role color, or customize it with `/quote color:#hex`.
- **Long-Press Context Menu:** Tap and hold any message in chat and select **Quote as PNG** for instant one-tap quoting.
- **Native Attachment Upload:** Uploads the generated PNG directly as a Discord attachment in the chat.
- **Configurable Settings:** Toggle the context menu button, customize default colors, and test quote generation in the plugin settings.

## Usage

- `/quote` *(while replying to a message)*: Quotes the replied message and sends the PNG card to the chat.
- `/quote text:your custom text`: Quotes your custom text.
- `/quote text:your text user:@user`: Quotes text attributed to a specific user.
- `/quote color:#5865f2`: Specifies a custom role/username color.
- **Long-press any message** → Tap **Quote as PNG** for instant quoting without typing.

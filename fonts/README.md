# Fonts

Custom typography font pack for Revenge / Vendetta.

## Included Fonts

- **Gauge (Gauge Heavy):** Replaces Discord's default font family (`ggsans-Normal`, `ggsans-Medium`, `ggsans-Semibold`, `ggsans-Bold`, `ggsans-ExtraBold`) with the bold and clean Gauge Heavy typeface.

## Installation

Add the font definition URL to Revenge/Vendetta (Settings → Fonts / Themes):
```
https://raw.githubusercontent.com/ilickft/revenge-plugins/main/fonts/Gauge.json
```
Or via GitHub Pages:
```
https://ilickft.github.io/revenge-plugins/fonts/Gauge.json
```
